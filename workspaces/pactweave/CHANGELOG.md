# Changelog

## 0.1.0 — Initial implementation

- One public PactWeave skill with rule-based request analysis and explicit Task Contracts.
- PactLoop bounded execution/review/repair and WeaveMesh registered-tool orchestration.
- PactVault scoped local context and a separate session response-cache interface.
- On-demand local Wiki/RAG retrieval and an optional central model Gateway.
- Shared deterministic browser/CLI logic, evidence records and explicit unsupported states.
- English-primary ProofNova presentation, Korean/Japanese/Simplified Chinese editions, and an edited version of the user's architecture illustration.

Release readiness is determined by the actual tests and saved verification records at the released commit. This changelog is not a substitute for those records or evidence of external user adoption.
